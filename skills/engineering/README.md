# Engineering

Production engineering and operational readiness. Ensuring what ships survives contact with real users at scale.

- **[production-ready](./production-ready/SKILL.md)** — Audit whether a feature or product is ready for production across error handling, observability, database safety, performance, deployment, resilience, and operational readiness.
- **[handoff](./handoff/SKILL.md)** — Turn conversation context into a spec and independently-grabbable vertical-slice issues for humans or agents.
- **[vibe-code-antipatterns](./vibe-code-antipatterns/SKILL.md)** — Audit a codebase for structural problems common in AI-generated code — god components, missing error handling, copy-paste duplication, inconsistent patterns, and happy-path-only logic.
- **[daily-standup](./daily-standup/SKILL.md)** — Scan the codebase, issues, and recent commits to generate a prioritized daily work plan of 36-48 hours of optimizations that compress to under 24 hours with agent assistance.
